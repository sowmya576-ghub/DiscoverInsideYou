# Fact-Check Checklist

Run this before signing off Gate 1 (Research), and again on the final script (Gate 2)
for any line that changed. Copy results into the video's `quality-check.md`.

## Sources
- [ ] Every source was actually opened and read (not inferred from a title or search snippet).
- [ ] Each URL is direct and works; title, publisher, and date match the page.
- [ ] Each source directly supports the specific claim it's attached to.
- [ ] Core claims rely on primary/authoritative sources, not popular media alone.
- [ ] Broad conclusions rest on reviews or converging evidence, not one study.
- [ ] Animal or in-vitro findings are labeled as such and not presented as human facts.
- [ ] Recent findings and medical guidance are current (access date recorded).

## Claims
- [ ] Every factual line in the script maps to a claim ID (`C#`) in `research.md`.
- [ ] No claim in the script is UNVERIFIED or REJECTED.
- [ ] QUALIFIED claims keep their qualifier in narration or on-screen text.
- [ ] Certainty words match the evidence level ("scientists think" ≠ "it is").
- [ ] Hypotheses, simplifications, and disputed points are identified as such.

## Numbers
- [ ] Each number matches the source exactly, including "about", "up to", ranges.
- [ ] Units are correct and consistent.
- [ ] Comparisons and analogies are proportionally correct (or flagged as rough).
- [ ] Timelines and sequences match the mechanism described in the source.

## Misconceptions and safety
- [ ] Known myths on this topic are identified and not accidentally reinforced.
- [ ] No diagnosis, treatment advice, or promised health outcome.
- [ ] Where health concerns are mentioned, viewers are pointed to a healthcare professional.

## Visual accuracy
- [ ] Each anatomical scene lists reference sources for structure, scale, and motion.
- [ ] Unobservable processes are flagged for a "Simplified model" label.
