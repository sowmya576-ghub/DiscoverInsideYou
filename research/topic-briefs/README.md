# Topic Briefs

Pre-production briefs for candidate topics, created from
[`templates/topic-brief.md`](../../templates/topic-brief.md). Each brief is named
`T###-slug.md` to match its row in [`topics/backlog.csv`](../../topics/backlog.csv).

A brief records the audience question, a preliminary answer from sources actually opened,
claims still to verify, caveats, and visual potential. **A brief is not finished
research.** Every claim is re-checked in the video's own `research.md` before scripting.
