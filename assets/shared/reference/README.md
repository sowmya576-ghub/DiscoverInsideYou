# Reference Images

Small reference images (anatomy figures, histology, diagrams) used to check visual
accuracy. These files **are tracked in git**, so keep each one small (< 1 MB, PNG/JPG).

Only add images you're allowed to store. Record each one below with its source and license.
For copyrighted figures, store only the link (not the file).
